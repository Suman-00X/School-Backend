Fonts embedded in every PDF (src/common/export/fonts.js) so names in Indian scripts,
Urdu and the ₹ sign print correctly. Regular and bold of each.

- Noto Sans (Latin/Greek/Cyrillic, ₹), Noto Sans Devanagari, Bengali, Tamil, Kannada,
  Malayalam, Gujarati, Oriya, Arabic: https://github.com/notofonts (OFL-Noto.txt)
- Hind Guntur (Telugu), Indian Type Foundry: https://github.com/google/fonts/tree/main/ofl/hindguntur (OFL-HindGuntur.txt)
- Mukta Mahee (Gurmukhi), Ek Type: https://github.com/google/fonts/tree/main/ofl/muktamahee (OFL-MuktaMahee.txt)
